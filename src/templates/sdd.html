Syntax-directed definitions

An SDD is stored as data: a grammar, an attribute table and one list of semantic rules per production. The evaluator parses the string, builds the dependency graph of the parse tree, orders it topologically and evaluates. If the graph has a cycle, the SDD is circular and evaluation stops.

Rules use X.attr, or $0 (head) and $1, $2… (body positions) when a symbol repeats. Expressions: arithmetic, comparisons, and/or/not, a if c else b, max min abs int str len.
